# Security policy

## Supported versions

Security fixes are applied to the latest release on the default branch.

## Reporting a vulnerability

Do not include secrets, private website data, or exploit details in a public
issue. Use the repository host's private vulnerability-reporting feature. If it
is unavailable, contact the maintainer through the private address published on
their repository profile.

This project processes untrusted JSON, Markdown, and HTML-like artifact content.
Reports about validation bypasses, unintended network access, path traversal,
or undeclared interactive controls are in scope.
