## [0.1.0] - 2026-08-24

### Added

- Evidence-backed website journey research and clickable flow-alignment skills.
- Generic wireframe and evidence-supported visual-reference adaptation modes.
- Codex plugin packaging, repository validation, and Python 3.10–3.14 CI.
- An owner-authorized Behind Your Day research-to-prototype demo.
- Contract enforcement for undeclared navigation, malformed specifications,
  path traversal, network restrictions, and evidence certainty.
- Optional runner-neutral Playwright audit for every declared transition,
  route-map jump, Restart behavior, action reachability, overflow, masks,
  spotlight geometry, and browser errors.

### Changed

- Builder initialization states its exact fragment-only scope, and wrapper
  failures name the exact missing marker instead of reporting a raw substring
  error.
